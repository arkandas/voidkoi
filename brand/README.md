# voidkoi brand kit

A white Tancho koi (the koi with a single red spot on its head), seen from above, swimming
upward through a circular void. The rim of the void is a gravitationally lensed crescent:
bright and thick at the lower-left, thinning to a cyan hairline at the upper-right. The O
of VOID in the wordmark repeats that crescent.

## Files (`brand/logo/`)

| File | Use |
|---|---|
| `void-koi-mark.svg` | Full-colour mark with glows and stars. Dark backgrounds, 64 px and up. Transparent outside the disk. |
| `void-koi-mark-flat.svg` | The same mark in flat colours, no filters. Light backgrounds, UI, 48–64 px. |
| `void-koi-mark-mono.svg` | One colour via `currentColor`, so it takes the CSS `color`. Stamps, single-colour print. |
| `void-koi-wordmark.svg` | VOIDKOI alone, `currentColor`. |
| `void-koi-lockup-dark.svg` | Mark and wordmark side by side, for dark backgrounds (site header). |
| `void-koi-lockup-light.svg` | Side by side, for light backgrounds (flat mark, ink text). |
| `void-koi-stacked-dark.svg` | Mark above wordmark, for dark backgrounds (splash, social). |
| `favicon.svg`, `favicon.ico` | Small-size build: bigger koi, heavier ring, no whiskers or fin gaps. The ICO holds 16, 32 and 48 px. |
| `apple-touch-icon.png` | 180 px, hero mark on a void square. |
| `icon-192.png`, `icon-512.png` | PWA icons, mark at 80% of the square so it survives maskable cropping. |
| `void-koi-mark-1024.png` | Raster of the hero mark for avatars and uploads. |

Don't edit these by hand. They're generated by `tools/logo/export.py`.

## Sign-in page (`brand/sign-in/`)

For the sign-in pages of an identity provider.

| File | Brand setting |
|---|---|
| `background.jpg` | Default flow background (2560×1440, ~100 KB). `background.svg` is its source. |
| `voidkoi-logo-light.svg`, `voidkoi-logo-dark.svg` | Logo, set as `voidkoi-logo-%(theme)s.svg` so each theme gets its own. |
| `voidkoi-favicon.svg` | Favicon. |

The background is the mark's lensed ring at page scale, as a horizon low on the page:
the login card sits in the sky above it and the provider's footer on the disk below. Regenerate
with `python3 tools/sign-in/background.py`.

## Using it

- On a dark UI, use the hero mark and the dark lockups. On a light UI, use the flat mark
  and the light lockup.
- Below about 48 px use `favicon.svg`, not a shrunk mark.
- Suggested clear space: a quarter of the disk's diameter on every side. Suggested
  minimum for the horizontal lockup: 160 px wide.
- Keep vermilion for the Tancho only.
- Don't recolour the koi, rotate or stretch the mark, add effects to the flat build, or
  put the glowing hero mark on a light background.

## Palette

| Name | Hex | Role |
|---|---|---|
| Void | `#08070D` | Page background |
| Abyss | `#0E0A1F` | The disk |
| Horizon | `#9D86FF` | Violet ring (flat builds), accents |
| Lens | `#63E6F7` | Cyan end of the lensed ring |
| Pearl | `#F7F5FF` | The koi |
| Tancho | `#FF4D2E` | The red crown spot, and the only warm colour |
| Ink | `#110E1C` | Wordmark on light backgrounds |
| Mist | `#F2EEFF` | Wordmark on dark backgrounds |

Gradients in the hero mark:
- Ring, from the lower-left: `#F5F1FF` → `#AC98FF` → `#6C4FE8` → `#63E6F7`.
- Disk, from the centre to the rim: `#0A0714` → `#0E0A1F` → `#28195A`.
- Koi, radial from the head: `#FFFFFF` → `#EFEBFF` → `#C2B4FF`.

## Type

The wordmark is custom geometry, not a font: wide geometric caps with a stroke of 12% of
the cap height, 34% tracking, and the O of VOID drawn as the lensed crescent. No typeface
has been chosen for the site yet.
